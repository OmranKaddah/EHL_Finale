This project is an EHL/Atira RFQ challenge agent. It must investigate four supplied business websites, gather citation-backed evidence, calculate a deterministic EUR offer, submit it through the tender portal, retrieve an email TAN when required, and verify the receipt within a 20-minute run.

The package is under `src/atira_agent/`:

- `runtime.py` / `config.py`: load Atira runtime data, enforce sandbox CDP-only browsers, choose Qwen through Atira’s proxy.
- `multi_agent.py`: browserless coordinator plus four model-directed specialists, each assigned one provided browser:
  - Tender: RFQ reference, positions, Q&A, amendments, submission portal.
  - Specifications: drawings, revisions, requirements, certifications.
  - ERP: exact material matches, stock, price, delivery, commercial conditions.
  - Mail: approvals, condition rules, superseded mail, TAN retrieval.
- `browser.py`: safe CDP browser tools, observations, semantic control references, frames/tabs/documents, modal detection.
- `evidence.py` / `contracts.py`: typed evidence ledger with source, exact excerpt, observation, timestamp, scope, and conflict/unresolved tracking.
- `business_rules.py` / `pricing.py`: pure `Decimal` pricing and tender rules—revisions, quantity amendments, material matching, FX/index rules, discounts, packaging, setup allocation, pooled stock, bonuses, and final rounding.
- `submit.py`: schema validation, portal form mapping, TAN/signing state machine, receipt verification.
- `dashboard.py` / `telemetry.py`: redacted JSONL events, traces, SSE local debugging dashboard, replay artifacts.
- `popup_classifier.py`: optional Clef-based sanitized popup classification. It is advisory only; Qwen still chooses actions.

The design goal is generalization: no hardcoded public-site routes, record IDs, page counts, scenario values, or page-specific adapters. Qwen must select observed controls and documents; deterministic code only validates evidence and performs calculations.

The main remaining gap is a successful official sandbox completion with an accepted receipt. Synthetic tests exercise signing, evidence, pricing, changed layouts, transient failures, session expiry, and TAN replacement. Public and sandbox rehearsals have shown genuine site interaction, but ERP can present an explicit robot-verification gate that blocks access to commercial evidence.
